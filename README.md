# Página web de prueba

Este repositorio quedó organizado para evitar archivos duplicados en la raíz.

## Estructura

```text
/
├── index.html
├── html/
│   ├── catalogo.html
│   ├── categoria.html
│   ├── cuenta.html
│   ├── moda.html
│   └── quienes-somos.html
├── css/
│   └── styles.css
├── js/
│   ├── cuenta.js
│   ├── productos.js
│   └── script.js
└── imagenes/
    ├── Polera Generica.jpg
    ├── Poleron Generico.jpg
    └── README.md
```

`index.html` se mantiene en la raíz porque GitHub Pages lo usa como página de entrada.

Los HTML secundarios están en `html/`, los estilos en `css/`, la lógica en `js/` y los recursos visuales en `imagenes/`.
