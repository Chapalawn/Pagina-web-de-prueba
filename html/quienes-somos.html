Quiénes somos

Este sitio fue creado como una prueba de una futura tienda de ropa en línea.

Nuestra idea

El objetivo de esta página es probar una estructura sencilla para presentar productos, categorías, precios, tallas y opiniones.

La información utilizada es genérica y sirve solamente como ejemplo para desarrollar y aprender el funcionamiento del sitio.

Más adelante, el contenido de demostración puede reemplazarse por una marca, productos e imágenes reales.

OBJETIVOS DEL PROYECTO

Una base simple y fácil de mantener

Simplicidad

Agregar nuevos productos sin tener que modificar toda la página.

Orden

Mantener productos, estilos y funciones separados en archivos fáciles de identificar.

Práctica

Aprender HTML, CSS y JavaScript mediante un proyecto real y visible.

Evolución

Poder ampliar la página más adelante con imágenes, usuarios, pagos o una base de datos.
